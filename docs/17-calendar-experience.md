# 17 — カレンダー体験

契約は変えない（[02](02-requirements.md) / [12](12-ui-design.md)）。カレンダーは運転しない。乗る対象は切符。掲示は線路を塞がない。載せるが if-then。網は ATS。Hub に掲示を常設しない。ATO しない。日常の発車・停車・再乗車を確認で阻まない。確認は不可逆な操作だけ。

体験が悪いのは仕様違いではない。**契約が日常操作と擦れていない。** 直すときはここを先に読む。画面の作りはコードを見る。

## ずれ

ユーザーがカレンダー連携に期待しがちなこと（今日の予定が仕事の材料になる、会議前に仕事が切れる、会議自体が仕事になる）と、製品の契約（予定は乗る対象ではない、状況認識は乗務の現場、載せるまで線路は空）は正反対に近い。

日常の中心は Hub の発車。発車・停車・再乗車は確認しない。載せる手は案内板の一行（今回だけ）とダイヤタブ。載せていないと保護は効かない。確認は不可逆な操作だけ。

## カレンダー上のものは一様ではない

時刻付き予定＝占有候補、としてしか見ていない。実際の予定は役割が違う。

| 種類 | 載せる | 載せない |
|------|--------|----------|
| 不可避の会議（1on1、面談） | 網の価値が高い。乗れない | 乗務中に気づかない |
| 任意・大会議 | 作業できない | 発車はできる。載せるまで網は無い |
| カレンダーに書いた集中ブロック | 走れない。本来乗りたい時間 | 掲示のまま |
| 期限だけの終日 / 仕事場所 / 誕生日 | 対象外で消える | 今日の休みが見えない |
| 仮 / 未回答 | 掲示される | 載せる判断ができない |
| 移動時間 | バッファなし | 帳場が足りない |

## シーン

見る・する・感じる。壊れる点は「感じる」。

### 初回

ダイヤタブを初めて開くと許可を求められ、24 時間の時計と用語が出る。Hub とは別世界に見える。載せるまで何も起きないのが伝わらない。

許可を断ると図表に琥珀が出るだけ。設定へは届かない。Hub は黙る。死んだ機能に感じる。

掲示するカレンダーを全部消すと掲示は消えるが、載せたダイヤは残る。隠す ≠ 外す、が図では分からない。

終日は静かに落ちる。休み・OOO・誕生日が状況認識にならない。

### 朝（Hub が中心）

運行を始めても、載せていなければ今日の会議は Hub に無い。「今日何があるか」はカレンダーアプリのほうが早い。ダイヤは毎日開かせない設計なのに、載せるには開くしかない。

今日の会議を載せるのは件数分のシート。一括はない。重複は同一の帯に重なる。掃き出しの摩擦と反対で、繰り返しウィザードに近い。

「今後も」は効いているか図表では確認しにくい。明日の図は無い。今夜、明日の重要会議を符号化できない。

外すシートは載せると対称に見えない。

### 発車（一番暑い経路）

発車は確認しない。未載せの会議中でも即走る。忙しい日に学校にしない。

載せた枠の直前に長い切符を発車すると、発車はできる。見積を縮める手は出ない。枠に入ると 60 秒で停車する。

載せた会議をスキップして走りたいとき、乗務現場で外す（今回だけ）。外さずに再乗車すると同じ網に戻る。外すまで決着しないのは網であり、確認ダイアログではない。

会議自体が仕事のとき、予定に乗れない。切符を別に出し、載せると会議中は走らせない。連携したのに作業が 2 倍に感じる。

### 乗務中

Focus のダイヤは題名一行。残り分は出ない。掲示は出さない。Lock / Live Activity / Widget にも出ない。Mac は題名だけ。「何分後に会議か」が計器として読めない。

AlarmKit が活性なら終了ベルが次のダイヤ開始に畳まる。終了の音が会議の音に感じる。ダイヤ用の知らせは出ない。

未載せの会議で他アプリへ行くと、車内放送が「まだ乗ってる？」。載せ忘れのペナルティが乗務の現場に出る。責めに感じる。

アプリを閉じて会議すると、停車は次に開いたとき境界へ遡る。自分で停めていないのに過去が書き換わる。説明はダイヤタブにしかない。

会議が終わっても静かな案内は残る。再乗車を忘れる。ADHD 的にそのまま別のことを始める。ATO で戻さない（[02](02-requirements.md)）。人が回せない隙間が残る。

ATS の停車は停車の枠を食う。会議のせいで新規発車できなくなる。

### 予定が動く

時刻がずれると、載せたつもりが消える。知らされない。取消は消えるだけで分からない。カレンダー側で足した予定は、開くまで図表に乗らないことがある。

### 図表

個人・仕事・ファミリーが最初から全部出る。早食い、Focus Time、Busy、仮の RSVP も掲示。場所も人数も色も無い。載せる価値が読めない。

短い予定が連続すると帯が潰れる。重なると下が見えない。

手動で時刻を引く起点が昼固定。「今から」ではない。朝に引くと過去になる。

履歴に載せたダイヤだけ重ねるのは守る。載せていない会議の上を走ったように見えるのは、記録として誠実でない。

## 直す順

契約（発車は止めない、日常の発車・停車・再乗車を確認で阻まない、Hub に掲示を常設しない、未載せだけで ATS しない、ATO しない、月表示・書き込み・「これに乗れ」をしない）は壊さない。確認は不可逆な操作だけ。

1. **発車を阻まない** — 確認で学校にしない。載せた枠の網は ATS。意図して走る手は乗務現場の外す。
2. **乗務現場の認識** — Focus / Mac / ロックで「何分後か」が読めないこと。未載せ会議での away。会議後に残る案内。
3. **載せる摩擦** — 件数分のシート、重複で潰れる図表、許可を断ったあとの行き場、終日が見えないこと、予定の移動が沈黙すること。

会議を切符にするのは最後。否定要件に触れる。材料にしたい気持ちは、発車と乗務の現場を直しても残るなら、そのときだけ問い直す。

直すときの試し: 忙しい日に、載せ忘れのまま発車しても学校にならない。載せた会議を意図して走れる。乗務中に次の枠までが計器として読める。載せる手は残るが、件数でウィザードにならない。
