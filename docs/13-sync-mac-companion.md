# 13 — 同期構成（なぜこの形か）

ワイヤのバイト・経路・黄金 JSON の正本は [`sync/contract/`](../sync/contract/README.md)。Mac の体験は [14](14-mac-companion-ux.md)。製品の守ること・やらないことの正本は [02](02-requirements.md)。

## なぜこの形か

iPhone の SwiftData + `SessionManager` が本尊。リレーは正本にしないし、復号できない。

運ぶのは **いまの乗務** の暗号スナップショットと、コマンド `pause` / `resume` / `still` だけ。到着・延長・切符全件レプリカ・CRDT は載せない。`arrive` / `extend` を足さない。

土管は Cloudflare Workers + pairing 1 = Durable Object 1。アカウントなし。起こし（APNs）を求めない。iOS は前面、または `ScenePhase.active` で送受信する。Personal Team のまま動く。

機密: 正規ユーザー以外は中身を見られない（Apple / 自前サーバ / 押収を含む）。だから CloudKit 私有同期はこの土管に使わない。鍵が Apple 側にある。暗号文だけ載せるなら自前同期と同じ仕事になる。

LAN / Bonjour は社内 Wi-Fi のクライアント分離で届かないことが多い。主経路にしない。

購読者は同じ契約ならよい。メニューバーであることは前提にしない。

## ペアリングの脅威

画面は常時録画されている前提。スクショも後ろ撮りも、映像を別マシンで読むことも中の脅威。画面に出るものは全部漏れる。確定に使うのは **画面に出ない秘密** と **その場の本人確認** だけ。

照合数字は人の防御にしない（見ない）。「どの Mac か」は、画面を机の Mac に向ける同時光学交換（セルフィー）。「本人か」は光学のあと、端末を自分に戻してからの Face ID / Touch ID。セルフィー中は顔が画面側に無いので、同じ姿勢で Face ID しない。

両方のカメラが揃うまでリレーに相手を固定しない。片側の QR 読取や「許可しますか」だけでは、録画の先着がペアになる。双方の本人確認が終わるまで Keychain に書かない。

`masterKey` / `writeToken` / confirm HMAC は QR にも貼り付けにも出さない。点滅 QR で秘密を分割しない（全フレームが残る）。リカバリを出すなら書き写しのみ。QR にしない。

カメラ無し Mac の貼り付けフォールバックはやらない。ウェブカメラ必須。

サーバ侵害の残りは削除 DoS。許容する。

## この面のやらないこと

アカウント、APNs、LAN 主経路、サーバ側正本、画面に載る長期鍵、片側タップ確定、照合数字の目視、裏カメラへの持ち替え。CloudKit と JSON エクスポート同期は [02](02-requirements.md)。
