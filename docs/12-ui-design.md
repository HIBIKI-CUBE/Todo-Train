# 12 — UI 方針

**HIG を骨格に、列車メタファはアクセント。** 道具であること（[01](01-vision.md)）を崩さない。

コーチング UI・ウィザード・カスタム FAB・グラデ背景・ストリークゲージは増やさない。

## 面ごとの役割

日常面はシステム標準（Tab / Form / シート）。列車は Hub のマルス券と発車時の案内板、発行・到着の祝祭、**運行の起動／シャットダウン**。Focus は純黒の計器。Mac は運転台を複製しない（[14](14-mac-companion-ux.md)）。運行の端も Focus の純黒に寄せる。マルスの発行スクリムとは揃えない。

タブは切符 / ダイヤ / 履歴 / 設定。**ダイヤタブは今日の運転図表**（空きは折らない。濃いスジがダイヤ、薄いスジが掲示、今日の乗車、いまの印）。着発・通過はその図の上。タップは今回だけ。今後もは別ジェスチャ。凡例と手は図表の一部。掲示するカレンダーは図表のツールバーで選ぶ。月表示・書き込み・空きに切符を並べる・「これに乗れ」はしない。毎日開けという促しは出さない。

**Hub に掲示リストを常設しない。** `⋯` と設定にダイヤへの重複リンクも置かない。状況認識は Hub 運行のいま＋次（最大二行）、持ち上げた切符の下の案内板、Focus の計器。掲示も含む。関係・位置・熱は視覚。題名・時刻・分・いま／次・操作は文字。見出し・凡例・「して」は出さない。持ち上げた案内板は、今この切符に乗るかの判断と、予定の到着への決意。一眼で役割が取れる。発車 LED の対になる下の案内板は予定の桁が単独の主。見積の分は券面。主桁に分を並べて行先票と同じ文法にしない。同じ 60 分の 5 分セル。塗りが予定、山形が予測（桁は予定とずれたときだけ、山形のキャプション）、門が占有。Hub peek の同じ尺に占有の門。塗りと門の位置で余裕・ギリ・踏み越しが伝わる。枠がこの切符の到着窓に掛かるときだけセルが伸びて尺が寄り、燐光が熱を帯び、占有は行先票（題名が主、時刻と分は標識の時刻表、ガラス）。遠い枠は静かな 60 分のまま、行先は燐光の駅名標。キャプションに題名を並べない。予測は中央値が骨格で、率や延長の言い方、モデルの思考は出さない。開いている切符は裏で温め、持ち上げた切符は列の前に出す。骨格は到着ですぐ動き、モデルは題名・時間帯が変わったら取り直す。収まらなくても発車は止めない。Focus と PiP は乗務の進捗バーに占有の帯と印を重ねる。停車が主操作のまま。発車・停車・再乗車は確認しない。ダイヤと重なれば ATS が網になる。着発／通過は案内板の一行（今回だけ）。確認は不可逆な操作だけ。契約と日常が擦れていない点は [17](17-calendar-experience.md)。

履歴は時計であり、空き時間（サボり含む）を折り畳まない。ダイヤだけ薄いスジを重ねる。カレンダー全件は重ねない。信号色（緑 / 琥珀 / 赤）は到着・停車・超過にだけ意味を持たせる。状態語は非平常時のみ。段階色は予算比であり、固定の「残り 1 分」ルールではない。

発券の主経路はタイトル → Return（狙い直しゼロ）。よくある削除に Alert は出さない（Undo バナー。UndoManager はタイトル編集と混ぜない）。日常の発車をダイアログにしない。

レイアウト分岐は向きや `UIScreen.main` ではなく、今のシーンのサイズクラスと幅。マスター・ディテール分割や FAB は増やさない。

Live Activity / StandBy は視線用の短い帯。Clock 級フルスクリーンは不可能。残時間が主役で、操作は原則 1 つ。[07](07-research.md)。

## 祝祭だけ例外

発行と到着はマルス 8.5cm 乗車券を前面に出す。参照: [references/mars-joshaken.png](references/mars-joshaken.png)。

- 発行: 未使用券。破りはしない
- 到着: 同じ券を手元に出し、**自分で検札印を押す**。破りは放棄に見えるので使わない。定時・早着は印色と haptic だけ。超過でも核は同じ
- 定時運行: 終了直後の短いカプセルだけ
- 運行開始: Focus の盤。表示灯は順に点いてため、テープと秒尺は別々に振り切る。時計が本点灯してから実状態。占有の着発と編成の確認。後付けの光は足さない。主操作は切符へ。発車は待たない
- 運行終了: 同じ盤に今日の跡（履歴と同じ縮尺。空きは折らない）と履歴と同じ日次の事実（集中分。到着・途中下車・放棄は記録）。率・ランクは出さない。主操作は運行終了。落とすと盤が逆順で消える

やらない: 西洋ミシン目、角丸トースト、`tram.fill`、鮭色エド券、JR ロゴ地紋の複製、¥、偽駅名、コンフェッティ、点数。発行と到着を同じスクリム＋トーストに揃えない。運行の端に乗務票・受領・検札の流用・マスコン複製を足さない。

祝祭の水色マルス紙はセマンティック色にしない（紙色は固定）。券面に券種「切符」は刷らない（物体が切符なので冗長）。見積もり分は運賃欄の大きさに加え、60 分枠の印字スケール（残り時間ではない）。Hub の peek でもタイトルと分数が同時に読める。同じ尺の占有の門は印字（LED でも信号色でもない）。

## 行先票は駅名標

占有の題名は今日の停車駅。見た目は日本の駅名標の骨格だけ借りる。参照: [references/README.md](references/README.md)。

- 題名が主。短い日本語は字間を開ける
- いま／次は番号欄。路線色の帯。着発／通過はその帯の上
- LED の案内板は燐光のまま。ガラスと Focus は板

やらない: 社名ロゴ、駅ナンバリング（JY / C06）の複製、題名のローマ字、偽の隣駅、メトロ配色マニュアル。発車 LED（`>>> 発車`）は発車標のまま混ぜない。
