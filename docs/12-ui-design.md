# 12 — UI 方針

**HIG を骨格に、列車メタファはアクセント。** 道具であること（[01](01-vision.md)）を崩さない。

コーチング UI・ウィザード・カスタム FAB・グラデ背景・ストリークゲージは増やさない。

## 面ごとの役割

日常面はシステム標準（Tab / Form / シート）。列車は Hub のマルス券と発車時の案内板、発行・到着の祝祭に限る。Focus は純黒の計器。Mac は運転台を複製しない（[14](14-mac-companion-ux.md)）。

Hub で切符を持ち上げたときは、発車 LED と対の案内板で予定と予測を時刻と 60 分スケールの位置として出す。予測は中央値が骨格で、率や延長の言い方、モデルの思考は出さない。開いている切符は裏で温め、持ち上げた切符は列の前に出す。骨格は到着ですぐ動き、モデルは題名・時間帯が変わったら取り直す。次のダイヤがあるときは同じ 60 分スケールに印を足す。収まらなくても発車は止めない。

履歴は時計であり、空き時間（サボり含む）を折り畳まない。載せたダイヤは薄いスジとして重ねる。カレンダー全件は重ねない。信号色（緑 / 琥珀 / 赤）は到着・停車・超過にだけ意味を持たせる。状態語は非平常時のみ。段階色は予算比であり、固定の「残り 1 分」ルールではない。ATS は操作名にしない。

発券の主経路はタイトル → Return（狙い直しゼロ）。確認ダイアログを挟まない。よくある削除に Alert は出さない（Undo バナー。UndoManager はタイトル編集と混ぜない）。

レイアウト分岐は向きや `UIScreen.main` ではなく、今のシーンのサイズクラスと幅。マスター・ディテール分割や FAB は増やさない。

Live Activity / StandBy は視線用の短い帯。Clock 級フルスクリーンは不可能。残時間が主役で、操作は原則 1 つ。[07](07-research.md)。

## 祝祭だけ例外

発行と到着はマルス 8.5cm 乗車券を前面に出す。参照: [references/mars-joshaken.png](references/mars-joshaken.png)。

- 発行: 未使用券。破りはしない
- 到着: 同じ券を手元に出し、**自分で検札印を押す**。破りは放棄に見えるので使わない。定時・早着は印色と haptic だけ。超過でも核は同じ
- 定時運行: 終了直後の短いカプセルだけ

やらない: 西洋ミシン目、角丸トースト、`tram.fill`、鮭色エド券、JR ロゴ地紋の複製、¥、偽駅名、コンフェッティ、点数。発行と到着を同じスクリム＋トーストに揃えない。

券面に券種「切符」は刷らない（物体が切符なので冗長）。見積もり分は運賃欄の大きさに加え、60 分枠の印字スケール（残り時間ではない）。Hub の peek でもタイトルと分数が同時に読める。

マルス紙はダークモードにも運行状態にも従わない。未タグは固定の水色。タグがあるときだけ、チップと同じ色相の色紙にする（Hub の peek で群が読める明度）。信号色（緑 / 琥珀 / 赤）とは別。印刷・シリアル・検札印は紙が変わっても固定。
