# 12 — UI 方針

**HIG を骨格に、列車メタファはアクセント。** 道具であること（[01](01-vision.md)）を崩さない。

コーチング UI・ウィザード・カスタム FAB・グラデ背景・ストリークゲージは増やさない。

## 面ごとの役割

日常面はシステム標準（Tab / Form / シート）。列車は Hub のマルス券と、発行・到着の祝祭に限る。Focus は純黒の計器。Mac は運転台を複製しない（[14](14-mac-companion-ux.md)）。

履歴は時計であり、空き時間（サボり含む）を折り畳まない。信号色（緑 / 琥珀 / 赤）は到着・停車・超過にだけ意味を持たせる。状態語は非平常時のみ。段階色は予算比であり、固定の「残り 1 分」ルールではない。

発券の主経路はタイトル → Return（狙い直しゼロ）。確認ダイアログを挟まない。よくある削除に Alert は出さない（Undo バナー。UndoManager はタイトル編集と混ぜない）。

レイアウト分岐は向きや `UIScreen.main` ではなく、今のシーンのサイズクラスと幅。マスター・ディテール分割や FAB は増やさない。

Live Activity / StandBy は視線用の短い帯。Clock 級フルスクリーンは不可能。残時間が主役で、操作は原則 1 つ。[07](07-research.md)。

## 祝祭だけ例外

発行と到着はマルス 8.5cm 乗車券を前面に出す。参照: [references/mars-joshaken.png](references/mars-joshaken.png)。

- 発行: 未使用券。破りはしない
- 到着: 同じ券を手元に出し、**自分で検札印を押す**。破りは放棄に見えるので使わない。定時・早着は印色と haptic だけ。超過でも核は同じ
- 定時運行: 終了直後の短いカプセルだけ

やらない: 西洋ミシン目、角丸トースト、`tram.fill`、鮭色エド券、JR ロゴ地紋の複製、¥、偽駅名、コンフェッティ、点数。発行と到着を同じスクリム＋トーストに揃えない。

祝祭の水色マルス紙はセマンティック色にしない（紙色は固定）。
