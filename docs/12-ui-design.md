# 12 — UI 方針

**HIG を骨格に、列車メタファはアクセント。** 道具であること（[01](01-vision.md)）を崩さない。

コーチング UI・ウィザード・カスタム FAB・グラデ背景・ストリークゲージは増やさない。

## 面ごとの役割

日常面はシステム標準（Tab / Form / シート）。列車は Hub のマルス券と発車時の案内板、発行・到着の祝祭に限る。Focus は純黒の計器。Mac は運転台を複製しない（[14](14-mac-companion-ux.md)）。

タブは切符 / ダイヤ / 履歴 / 設定。**ダイヤタブは今日の運転図表**（空きは折らない。濃いスジがダイヤ、薄いスジが掲示、今日の乗車、いまの印）。載せる・外すはその図の上。凡例と「載せる／外す」の手は図表の一部。掲示するカレンダーは図表のツールバーで選ぶ。月表示・書き込み・空きに切符を並べる・「これに乗れ」はしない。毎日開けという促しは出さない。

**Hub に掲示リストを常設しない。** `⋯` と設定にダイヤへの重複リンクも置かない。状況認識は Hub 運行のいま＋次（最大二行）、持ち上げた切符の上の案内板、Focus の計器。未載せも含む。時刻と分数はレールと桁の計器。率や「して」は出さない。発車 LED の対になる下の案内板は予定と予測の時刻＋60 分スケール。予測は中央値が骨格で、率や延長の言い方、モデルの思考は出さない。開いている切符は裏で温め、持ち上げた切符は列の前に出す。骨格は到着ですぐ動き、モデルは題名・時間帯が変わったら取り直す。次の占有があるときは同じ 60 分スケールに印を足す。収まらなくても発車は止めない。停車が主操作のまま。発車・停車・再乗車は確認しない。載せた枠と重なれば ATS が網になる。いまの掲示を載せる／いまのダイヤを外すのは案内板の一行（今回だけ）。確認は不可逆な操作だけ。契約と日常が擦れていない点は [17](17-calendar-experience.md)。

履歴は時計であり、空き時間（サボり含む）を折り畳まない。載せたダイヤだけ薄いスジを重ねる。カレンダー全件は重ねない。信号色（緑 / 琥珀 / 赤）は到着・停車・超過にだけ意味を持たせる。状態語は非平常時のみ。段階色は予算比であり、固定の「残り 1 分」ルールではない。

発券の主経路はタイトル → Return（狙い直しゼロ）。よくある削除に Alert は出さない（Undo バナー。UndoManager はタイトル編集と混ぜない）。日常の発車をダイアログにしない。

レイアウト分岐は向きや `UIScreen.main` ではなく、今のシーンのサイズクラスと幅。マスター・ディテール分割や FAB は増やさない。

Live Activity / StandBy は視線用の短い帯。Clock 級フルスクリーンは不可能。残時間が主役で、操作は原則 1 つ。[07](07-research.md)。

## 祝祭だけ例外

発行と到着はマルス 8.5cm 乗車券を前面に出す。参照: [references/mars-joshaken.png](references/mars-joshaken.png)。

- 発行: 未使用券。破りはしない
- 到着: 同じ券を手元に出し、**自分で検札印を押す**。破りは放棄に見えるので使わない。定時・早着は印色と haptic だけ。超過でも核は同じ
- 定時運行: 終了直後の短いカプセルだけ

やらない: 西洋ミシン目、角丸トースト、`tram.fill`、鮭色エド券、JR ロゴ地紋の複製、¥、偽駅名、コンフェッティ、点数。発行と到着を同じスクリム＋トーストに揃えない。

祝祭の水色マルス紙はセマンティック色にしない（紙色は固定）。券面に券種「切符」は刷らない（物体が切符なので冗長）。見積もり分は運賃欄の大きさに加え、60 分枠の印字スケール（残り時間ではない）。Hub の peek でもタイトルと分数が同時に読める。
