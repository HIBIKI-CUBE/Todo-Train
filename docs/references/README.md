## 運行の機体（起動／シャットダウン）

原画ファイルは置かない。マスコン・社名・英語の POST・走査線は複製しない。

起動の門は閉じた運転台の内側。Focus の純黒と行先票の文法を借りる。自己診断の進行を主人にしない。光は棚面と文字を照らす。開くのはホームへであり、シートの閉じではない。シャットダウンは同じ盤の振り切り。

| 参照 | 借りる点 | 借りない点 |
|------|----------|------------|
| Focus の計器盤 | 純黒、占有の行先票、編成 | 乗車の残り時間、診断パネルの進行 |
| E233 計器モニタの表示灯（速度計の上。文字が灯） | 文字が灯そのもの。運行・占有・編成 | ATS 灯、列番、マスコン、起動の主人 |
| 閉じた場所 → 火入れ → 揃え → 用意 → 広い面 | 感情の構造 | 映像の直写、SF 語彙 |
| 自動車クラスタの BIT | シャットダウンの針の振り切り | 起動の主人にしない |
