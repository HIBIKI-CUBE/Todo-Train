# 01 — ビジョンと哲学

## 一言

列車の切符をモチーフにした、個人向けタスク管理・作業トラッキングアプリ。  
**タスク管理がハブ**であり、日々の運用をストレスフリーにすることを最優先する。

## 三本柱

| 柱 | 内容 |
|----|------|
| **切符型タスク管理** | 1タスク = 1切符。Hub が日常の中心 |
| **集中実行（乗車）** | フォーカス専用ビューで 1 タスクに閉じ込める（アプリ内） |
| **見積もり精度の学習** | 実績との差から、**アプリなしでも見積もれる**感覚を身につける |

## 設計哲学（確定）

1. **当面は自分専用**（将来 App Store 公開もあり得る）
2. **コーチではなく道具** — 介入しすぎない。ガイドが集中リソースを奪わない
3. **外付けストレージ（brain-dump）** — 「あれやらなきゃ」を即座に掃き出す
4. **意志ある並べ替え** — システム自動ソートなし
5. **明示的な到着** — フォーカス終了 ≠ タスク完了
6. **咎めない** — Override 等は罰しない。自己認識用の記録のみ
7. **習熟で速くなる操作は歓迎** — デフォルトパスは単純、上級操作は別ジェスチャ（Mars 的）
8. **定時の喜びは瞬間、通貨にしない** — **まず到着できたことを短く味わう**。定時・早着はいい結果として味付けする。点数・ストリーク・定時率は作らない。超過を理由に祝祭を取り下げない

## ターゲット環境

| 項目 | 値 |
|------|-----|
| 端末 | iPhone 15 Pro Max 前提 |
| OS | iOS 27 |
| AI | Apple Intelligence + PCC（v1）。古い端末フォールバックは不要 |
| UI | SwiftUI |
| 永続化 | SwiftData（MVP はローカルのみ） |

## 成功の定義

- 頭のタスクを摩擦なく掃き出せる
- 1 枚ずつ乗務して、見積もりと実績の感覚が育つ
- 「アプリに閉じ込められた」ではなく「道具として使える」感覚
