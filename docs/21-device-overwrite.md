# 21 — 実機への上書き

スキーマや約束を変える PR は、マージ前にこの手順を通す。ストアの形を変えない約束の変更でも、上書きで件数が減らないことと、「このビルド」が入れたビルドを指すことを見る。

#71 より前のビルド（`ad1a5d8`）は、#71 より後のストアが残っている唯一の端末には入れない。その確認は別の端末で行う。

## バックアップ

1. Xcode の Devices and Simulators で iPhone を選ぶ。
2. インストール済みの Todo train（bundle id `dev.hibiki-cube.Todo-train`）を選び、Download Container する。
3. 保存した `.xcappdata` を残す。store は `AppData/Library/Application Support/default.store` と、同じ場所の `-wal` / `-shm`。
4. 戻すときは同じ画面の Replace Container。

#71 より後の store に上書きする前に、アプリを消さない。

## いまの端末へ上書きする

1. 上書き前に、時刻表（`TimetableBlock`）、走行（`WorkSession`）、乗客（`PassengerRide`）、予約のある切符の件数を控える。予約と到着の印も見る。
2. 同じ bundle id のまま、確認するビルドを今のアプリの上にインストールする。
3. 4 種の件数が減っていないこと、予約と到着の印が残っていることを見る。設定の「このビルド」が、入れたコミットとストアの版を指していることを見る。スキーマを上げた PR では、その行の版が新しいスキーマの版である。約束だけを変えた PR では、ストアの版は上がらず、コミットが入れたビルドである。
4. 何か欠けていたら、バックアップの `.xcappdata` を Replace Container で戻す。

## #71 より前のビルドから（別の端末）

唯一の #71 より後の store に、それより前のビルドを入れない。新しい store は古いビルドで開かないことがある。バックアップは残したままにする。

1. 別の端末を使う。手元の #71 より後の端末のアプリは消さない。
2. #71 のマージ `f528119` の親 `ad1a5d8`（2026-10-11 12:56 JST の直前）をインストールする。
3. 時刻表、走行（`WorkSession`）、乗客、切符を少なくとも 1 件ずつ入れる。この時点の切符に予約の列はない。
4. アプリを消さずに、確認するビルドを上書きインストールする。
5. 時刻表、走行、乗客、切符のどれも件数が減っていないことを見る。「このビルド」が、上書きしたビルドとストアの版を指していることを見る。
6. 手元のデータを戻すなら、#71 より後のバックアップを Replace Container する。その復元は、バックアップを取った端末で行う。
