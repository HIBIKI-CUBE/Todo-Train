## Hub

```
┌─────────────────────────────────────┐
│ [編集]          Todo train    […][＋]│
├─────────────────────────────────────┤
│ 運行中 · 停車 1/2 · [運行終了]       │
├─────────────────────────────────────┤
│ 切符名  30分  ●タグ          [発車] │
│ …                                    │
├─────────────────────────────────────┤
│ タブ: 切符 ｜ 履歴 ｜ 設定            │
└─────────────────────────────────────┘
```

- 運行前は発車不可 → 運行開始を促す
- 完了切符は非表示
- 停車中はバッジ
- 行タップ → 詳細 / 横ボタン → 発車
- 未乗車・停車中の切符はフルスワイプ（または削除タップ）で即削除。下部バナーでしばらく **取り消す** 可
- 編集は並べ替え。詳細の「切符を削除」も即削除＋取り消し
- タグ・並べ替えは `…` メニュー

## クイック追加

```
ツールバー ＋ → シート（medium/large）
  → タイトル即フォーカス
  → 見積もりチップ（タイトル入力済みなら即発行）/ 任意分
  → 挿入位置（末尾デフォルト / 先頭 / 特定切符の直後）
  → タグ（任意・チェックリスト）
  → 「追加」で連続掃き出し（キーボード維持）
  → 「完了」で閉じる
```
## Focus

真っ黒背景の **ギャップレス・ダッシュボード**。余白カードではなく hairline で区切ったパネル格子。

```
┌──────────────────┬────────┐
│ 切符タイトル      │ 終盤   │  ← 状態語は非平常時のみ（終盤／まもなく／超過）
├──────────────────┴────────┤
│                           │
│         12:34             │  ← 画面の大半を占める超大タイマー（色は予算比で段階変化）
│                           │
├───────────────────────────┤
│ ▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░ │  ← 進捗バー（経過の塗りのみ）
│ 予定 14:32    見積もり 30分│
├───────────────────────────┤
│          到着             │
├────────────┬──────────────┤
│    停車    │   +延長      │
├────────────┴──────────────┤
│        途中下車           │
└───────────────────────────┘
```

色段階（固定1分ではない。`budget` に対する残り）:

| 段階 | 条件 | 表示 |
|------|------|------|
| cruise | 余裕 | 白・状態語なし |
| approach | 残り ≤ max(25%, 90s) | 薄琥珀・「終盤」 |
| final | 残り ≤ max(10%, 30s) | 琥珀・「まもなく」 |
| overtime | 残り < 0 | 赤・「超過」 |

- 停車枠・他切符は出さない
- portrait: 操作盤は高さの約 38%
- compact 横向き: 左に計器、右に操作盤（幅の約 40%）

超過時（タイマー可視のまま、操作盤のみ差し替え）:

```
切符タイトル              超過
         2:15
▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
予定を超過     見積もり 30分
もう終わってた / ちょうど終わった / 延長する
```

延長 UI: 操作盤を同じパネル格子で差し替え。`+5 / +10 / +15` の大セル＋理由 2×2。compact は分セルのみ。再プロンプトは延長のたび。

## 停車上限シート

最上部: **先に停車中を解決**  
その後: 今の切符を途中下車して整理 / 放棄 / 臨時停車許可（最下部）

## 到着整理キャンバス

質問なし。空行を並べて自分で掃き出す。

- 各行: タイトル + 見積もり。フルスワイプで行を消す（未発行。最後の 1 行は空行に戻す）
- 挿入位置ピッカー（共通コンポーネント）
- 「残りなし」で子 0 枚確定可
- AI 分割提案はタップ時のみ + PCC 注釈（stub）

## 運行終了

```
停車中の切符 → 各行で途中下車（乗り継ぎ掃き出し）または放棄
  → 未解決があると運行終了不可（持ち越しなし）
走行中がある → 先に停車/到着を要求
日付跨ぎ → Hub で運行終了シートを自動提示（Focus 中は解決後）
```

## 履歴

- MVP: セッション一覧 + 乗り継ぎリンク
- sticky 日次 stats、検索、「今日に追加」
- 行フルスワイプでそのセッションを削除。最後の記録なら切符も消える。バナーで取り消せる

## 切符詳細

- 開いている切符: タイトル・見積・期限・タグ編集、発車/再乗車
- 閉じた切符: 読み取り専用 + 乗り継ぎ・セッション一覧
- 「切符を削除」で物理削除（関連セッションも cascade）。走行中・停車中も可。バナーで取り消せる
- 終了済みセッションは行スワイプで個別削除（最後なら切符も削除して詳細を閉じる。取り消し可）

## 挿入位置ピッカー（共通）

選択肢: 先頭 / 末尾（デフォルト） / 特定切符の直後  
新規追加・乗り継ぎ発行の両方で再利用。
