## Hub

```
┌─────────────────────────────────────┐
│ 運行中 │ 走行 0 │ 停車 1/2 │ [運行終了] │
├─────────────────────────────────────┤
│ ┌─切符────────────────┐  [発車]    │
│ │ タイトル  30m  ●タグ │           │
│ └─────────────────────┘           │
│                          [＋ FAB]  │
└─────────────────────────────────────┘
```

- 運行前は発車不可 → 運行開始を促す
- 完了切符は非表示
- 停車中はバッジ
- カードタップ → 詳細 / 横ボタン → 発車

## クイック追加

```
FAB → 即キーボード
  → タイトル → Return
  → 見積もりチップ 1 タップ
  → 末尾挿入（変更は長押し等）
  → 連続追加（キーボード維持）
```

## Focus

```
タスク名
  12:34   ← カウントダウン
見積もり 30m / 延長 +10m

[ 停車 ]  [ 到着 ]  [ +延長 ]
 →Hub      →Hub      留まる
```

超過時:

```
🔔 見積もりを過ぎました
[ もう終わってた ] [ ちょうど終わった ] [ 延長する ]
```

延長 UI（MVP）: `+5 / +10 / +15` + 任意理由 1 行。再プロンプトは延長のたび。

## 停車上限シート

最上部: **先に停車中を解決**  
その後: 今の切符を途中下車して整理 / 放棄 / 臨時停車許可（最下部）

## 到着整理キャンバス

質問なし。空行を並べて自分で掃き出す。

- 各行: タイトル + 見積もり
- 挿入位置ピッカー（共通コンポーネント）
- 「残りなし」で子 0 枚確定可
- AI 分割提案は v1・タップ時のみ + PCC 注釈

## 運行終了

```
停車中の切符 → 途中下車
  → 乗り継ぎ切符を掃き出しキャンバスで発行
  → 行ごとに放棄も可
走行中がある → 先に停車/到着を要求
```

## 履歴

- MVP: セッション一覧 + 乗り継ぎリンク
- v1: sticky 日次 stats、検索、「今日に追加」

## 挿入位置ピッカー（共通）

選択肢: 先頭 / 末尾（デフォルト） / 特定切符の直後  
新規追加・乗り継ぎ発行の両方で再利用。
