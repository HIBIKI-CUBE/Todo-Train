## Hub

```
┌─────────────────────────────────────┐
│                 Todo train    […][＋]│
├─────────────────────────────────────┤
│ 運行中 · 停車 1/2 · [運行終了]       │
├─────────────────────────────────────┤
│ （停車中があれば琥珀ブロック）         │
├─────────────────────────────────────┤
│  peek（後ろの券・覆われて見える帯）  │
│  peek                                │
│  ┌─────────────────────────────┐    │
│  │ 手前の券（全面可視）          │    │
│  └─────────────────────────────┘    │
│  ※タップ → 提示レイヤ（看板は中央固定。券が枠へ。出入りは手前券の下） │
│  ※発行後はリストのまま（祝祭を見る）   │
├─────────────────────────────────────┤
│ タブ: 切符 ｜ 履歴 ｜ 設定            │
└─────────────────────────────────────┘
```

- 運行前は発車不可 → 運行開始を促す
- 完了切符は非表示
- 停車中はスタック外（琥珀ブロック）＋再乗車
- peek タップ → **同じ券**が Hub の提示レイヤへ（リストのスロットには実券を残し、見た目だけ消す）。LED「>>> 発車 >>>」は **タブより上の中央に固定**（選択中だけ見える）。券がその枠へ滑り込む（スタックの手前券の下から抜ける。座ったら最前面）。右に明確に投げる＝**発車**。左／下／券面タップ／dim＝**戻す**（看板は一緒に飛ばない。動く券は手前券の下へ潜ってから渡す）。看板の高さは券の約 6 割（中に収める）。詳細は長押しメニュー。スロット↔中央は同一の提示 pose
- 未選択 peek のフルスワイプ（リストの `allowsFullSwipe` 相当）: **leading＝発車**、**trailing＝削除**（LTR では右／左）。部分スワイプは着席に戻す。運行前など発車不可の leading はゴムで戻す。削除は即反映＋ Undo バナー。VoiceOver はカスタムアクション（横フリックは VO の移動に使う）
- 発車は投げた位置から即 Focus（**提示中の券**が zoom source。Hub 上の黒待ちはしない。券の reverse morph は走らせない）
- 単発発行後は **リストに戻る**（自動で focus を開かない。発券祝祭を遮らない）
- 手前（一番下）は全面可視。後ろの券は重ねで隠れるだけ（全員を同高 peek clip しない）
- 未乗車はコンテキストメニュー、未選択 trailing フルスワイプ、または詳細で即削除。停車中はコンテキストメニュー（または詳細）。下部バナーでしばらく **取り消す** 可
- 並べ替えは `…` → `ReorderView`（スタック内 D&D なし）
- タグ・並べ替えは `…` メニュー

## クイック追加（親指発券帯）

片手親指・狙い直し最小化。ゴールデンパスは確認ダイアログなし。

```
ツールバー ＋ → シート（medium/large）+ 即キーボード
  → タイトル入力
  → Return / ゲージ離し ＝ 同一 `commitIssue`（狙い直し 0 / 1）
  → 巨大数字が現在値の真実源（スクラブ中ライブ）
  → タグはタイトル下に常時（横スクロール・ガラスチップ）。sticky・自動選択なし
  → 見積もりはセッション sticky（直前発行分を維持）
  → ゲージ長押し: 挿入位置（H-04）
  → 巨大数字長押し: 任意分
  → 発行後（単発・デフォルト）: コミット即マルス券排出（シート閉じと並列）。実券は隠しておき、ホールド後にデッキへ着地。下スワイプでホールド省略。読ませる ~2.5s
  → 発行後（連続トグル ON）: シート／KB 維持。褒めは selection haptic ＋ Undo のみ（切符演出なし）
  → 数秒 Undo（連続時） / 閉じる: 下スワイプ（または「完了」）
```

- ナビバーに「追加」は置かない（上部は片手の死角）
- Disclosure「詳細」は使わない
- ゲージは見た目も指も分比例（100%=60）。各停泊に sticky、閾値超えで隣へスプリング着地
- 停泊: 5 / 10 / 15 / 20 / 30 / 45 / 60
- 連続トグルは発券帯に配置。シートを閉じると OFF に戻る
- Return とゲージ発行は同一 `commitIssue` 経路。タイトル入力済みで発行するときゲージ detent は抑える
- **Focus 割り込み**: 同じシート。連続掃き出しは出さない。単発発行で今の切符を停車し、マルス券をいつもどおり出してからその券へ Zoom して発車。Hub のデッキ着地はしない

## Focus

真っ黒背景の **ギャップレス・ダッシュボード**。余白カードではなく hairline で区切ったパネル格子。

```
┌──────────────────┬────────┐
│ 切符タイトル      │ 終盤   │  ← 状態語は非平常時のみ（終盤／まもなく／超過）
├──────────────────┴────────┤
│                           │
│         12:34             │  ← 画面の大半を占める超大タイマー（色は予算比で段階変化）
│                           │
├───────────────────────────┤
│ ▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░ │  ← 進捗バー（経過の塗りのみ）
│ 予定 14:32    見積もり 30分│
├───────────────────────────┤
│          到着             │
├────────────┬──────────────┤
│    停車    │   +延長      │
├────────────┼──────────────┤
│   割り込み  │   途中下車    │
└────────────┴──────────────┘
```

色段階（固定1分ではない。`budget` に対する残り）:

| 段階 | 条件 | 表示 |
|------|------|------|
| cruise | 余裕 | 白・状態語なし |
| approach | 残り ≤ max(25%, 90s) | 薄琥珀・「終盤」 |
| final | 残り ≤ max(10%, 30s) | 琥珀・「まもなく」 |
| overtime | 残り < 0 | 赤・「超過」 |

- 停車枠・他切符は出さない
- **割り込み**: 3段目左。同じ発券シート → 単発で今の切符を停車。マルス券を出してから Zoom で Focus に入る。超過 3 択中は出さない
- **車内放送**: 超過と同じ操作盤差し替え。ヘッダ右に問い（「まだ『…』？」）。4 択: まだこれ / 停車 / 延長しそう / もう終わってた。次の放送までのカウントは出さない。超過中は出さない
- portrait: 操作盤は高さの約 38%
- compact 横向き: 左に計器、右に操作盤（幅の約 40%）
- **到着案内**: 到着したら Focus が閉じる動きが検札券の出現になる。検札印を自分で押す（破りはしない）
- **定時到着 / 早着**: 印色と haptic の味付けのみ。見積/実績のトーストは出さない
- 超過後の到着も同じ検札（差を突き付けない）

超過時（タイマー可視のまま、操作盤のみ差し替え）:

```
切符タイトル              超過
         2:15
▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
予定を超過     見積もり 30分
もう終わってた / ちょうど終わった / 延長する
```

延長 UI: 操作盤を同じパネル格子で差し替え。`+5 / +10 / +15` の大セル＋理由 2×2（仕事が膨らんだ / 割り込みが入った / まだかかる / その他）。compact は分セルのみ。再プロンプトは延長のたび。

車内放送（タイマー可視のまま、操作盤のみ差し替え）:

```
切符タイトル              まだ『資料』？
         12:34
▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░
予定 14:32    見積もり 30分
まだこれ
停車 | 延長しそう
もう終わってた
```

背面（走行中・scene 非 active）: 45–90 秒で Time Sensitive「まだ乗ってる？」＋ 停車 / まだやってる。進捗放送と同時なら away は捨てる。AlarmKit は使わない。設定「車内放送」OFF で沈黙。

## 停車上限シート

最上部: **先に停車中を解決**  
その後: 今の切符を途中下車して整理 / 放棄 / 臨時停車許可（最下部）

## 到着整理キャンバス

質問なし。空行を並べて自分で掃き出す。

- 各行: タイトル + 見積もり。フルスワイプで行を消す（未発行。最後の 1 行は空行に戻す）
- 挿入位置ピッカー（共通コンポーネント）
- 「残りなし」で子 0 枚確定可
- AI 分割提案はタップ時のみ + PCC 注釈（stub）

## 運行終了

```
停車中の切符 → 各行で途中下車（乗り継ぎ掃き出し）または放棄
  → 未解決があると運行終了不可（持ち越しなし）
走行中がある → 先に停車/到着を要求
日付跨ぎ → Hub で運行終了シートを自動提示（Focus 中は解決後）
定時運行 → 到着が1件以上かつ遅延なし（早着可）なら、終了直後に短い案内（件数・率は出さない）
```

## 履歴

- MVP: セッション一覧 + 乗り継ぎリンク
- sticky 日次 stats、検索、「今日に追加」
- 行フルスワイプでそのセッションを削除。最後の記録なら切符も消える。バナーで取り消せる
- 定時は「定時」、早着は「早着」。日次ヘッダに定時率は出さない

## 切符詳細

- 開いている切符: タイトル・見積・期限・タグ編集、発車/再乗車
- 閉じた切符: 読み取り専用 + 乗り継ぎ・セッション一覧
- 「切符を削除」で物理削除（関連セッションも cascade）。走行中・停車中も可。バナーで取り消せる
- 終了済みセッションは行スワイプで個別削除（最後なら切符も削除して詳細を閉じる。取り消し可）

## 挿入位置ピッカー（共通）

選択肢: 先頭 / 末尾（デフォルト） / 特定切符の直後  
新規追加・乗り継ぎ発行の両方で再利用。
