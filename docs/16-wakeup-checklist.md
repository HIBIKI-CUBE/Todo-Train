# 16 — 人が見ないと閉じない確認

コードでは閉じない実機と目視だけ。

## 車内放送 / Live Activity

- [ ] 終了ベル OFF・他アプリへ退避（画面オン）→ 数十秒で Session LA alert「まだ乗ってる？」→ 停車が効く
- [ ] ロックして作業 → away 通知も LA alert も出ない
- [ ] 終了ベル ON・同じ退避 → away が Alarm LA に重ならない
- [ ] 走行中 Session LA の停車 → LA は残り、再乗車できる
- [ ] ロック中の Intent 認証（停車 / 停止）

## iOS セルフィー

- [ ] 設定に Mac セクション。つながったあとはコンピュータ名とペア識別子
- [ ] 発車すると（前面のまま）Mac に乗務が出る。再起動した iPhone が既に乗務中でも出る
- [ ] 発車・停車・到着が「つなぎ直す」なしで追いつく
- [ ] 画面を Mac に向ける。Face ID は光学のあと、自分に戻してから
- [ ] 前面復帰の停車 cmd が既存の停車に乗る（上限なら止まらず ack だけ）
- [ ] CloudKit / iCloud capability は増えていない
- [ ] 発券・Focus・停車 LA が壊れていない

## macOS メニューバー

- [ ] Dock なしで extra が出る。未ペアクリックが大きな正方カメラ。Touch ID は自動
- [ ] iPhone がつながったあと、Mac も「つながった」になる（オファーを消して Mac だけ失敗しない）
- [ ] 吹き出しを閉じるとカメラインジケータが消える
- [ ] 乗務中 PiP が四隅へスナップする。左右の外へ十分ドラッグすると同じカードのまま画面の外へ出る。自動では隠さない。隣のディスプレイへは移る
- [ ] ホバーで停車 / 再乗車。前面アプリのキー入力を奪わない。フルスクリーンの上にも残る
- [ ] 乗務なし・未ペアでは PiP が出ない。超過は表示だけ
- [ ] 送信中は「iPhone に送った」。同じ cmd を連打しない
- [ ] 歯車は設定。吹き出しの末尾と右クリックで終了。右クリックの設定…は歯車と同じ。設定から解除できる
- [ ] 長い切符で PiP に「まだ乗ってる？」。片方で答えたらもう片方は出ない
- [ ] 運行は開いて乗っていない: 「運行は続いてる」が通知だけ（PiP なし）。ペアしても iPhone の idle は残る。Hub を眺めただけでは延びない

## カレンダー占有

- [ ] Hub 運行に、載せていない会議でも「いま／次」が出る。時刻と残り分が読める。リストではない。切符を持ち上げなくても読める
- [ ] Focus と案内板にも同じ占有が出る。載せる／外すは今回だけ。発車は確認しない
- [ ] 載せた枠で ATS 停車したあと、停車上限を食わずに別の切符を発車できる。枠が終わると静かな案内が消え、再乗車が見える。自動では戻らない
- [ ] Mac PiP に未載せの占有が一行出る。時刻・残り分・題名
