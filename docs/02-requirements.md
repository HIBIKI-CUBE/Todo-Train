# 02 — 確定要件・却下・未決

## 確定要件

### タスク（切符）

| ID | 内容 |
|----|------|
| T-01 | 各タスクは列車の切符モチーフ |
| T-02 | 属性: 名前、タグ、見積もり、（期限は v1 defer） |
| T-03 | 見積もり **上限 60 分** |
| T-04 | プリセット: **5 / 10 / 15 / 20 / 30 / 45 / 60** 分 |
| T-05 | 任意カスタム入力は v1 で検討（MVP 必須ではない） |
| T-06 | 開始済みは進捗比率（実績/見積もり）を表示可能 |
| T-07 | タグ: 色+名前、複数可、管理画面の並び最上位=デフォルト |
| T-08 | タグ初期プリセットなし |
| T-09 | 1 切符に何度でも乗車可（停車→再発車） |
| T-10 | 完了はアーカイブ（Hub 非表示、履歴に残る） |
| T-11 | 繰り返しタスク不要 → 履歴から「今日に追加」（**v1**） |
| T-12 | 既存切符の大幅書き換え禁止 → **分割のみ** |
| T-13 | 子タスクは **乗り継ぎ** リンクで系譜をたどる |
| T-14 | 新規作成時に挿入位置指定可（デフォルト末尾） |
| T-15 | 乗り継ぎ先作成時も挿入位置指定 |

### Hub / Inbox

| ID | 内容 |
|----|------|
| H-01 | 随時追加のインボックス型 |
| H-02 | FAB → **即キーボード**、連続追加 |
| H-03 | タイプ → 見積もりチップ 1 タップ → 完了 |
| H-04 | 挿入位置変更: 見積もりチップ長押し等（上級操作） |
| H-05 | カードタップ=詳細、横に発車ボタン |
| H-06 | ミニマルカード + 列車テーマ |
| H-07 | 停車中を Hub にバッジ表示 |
| H-08 | 同時停車の上限 **デフォルト 2**（設定で 3）。停車はいつでも可。上限では **新規発車** を止める |
| H-09 | 走行中は同時 **1** 件のみ |
| H-10 | MVP: Hub 内ドラッグ並べ替え。専用並べ替えビューは **v1** |
| H-11 | Inbox 総数にハード上限なし |
| H-12 | **タグ UI は MVP に含む** |
| H-13 | App Intent「切符を発行」。見積は Heuristic 中央値 → 直前発行 → 30 分。発車はしない。発行祝祭は Hub 経路のみ |

### 運行（Service Day）

| ID | 内容 |
|----|------|
| S-01 | **運行開始 / 運行終了** で 1 日のメリハリをつける |
| S-02 | **発車は運行中のみ** |
| S-03 | 日付が変わったら翌日起動時に運行終了フローを出す |
| S-04 | 運行終了時、停車中・未到着は **途中下車 → 乗り継ぎ切符**（行ごとに放棄可） |
| S-05 | 走行中は運行終了不可（先に停車/到着） |

### フォーカス

| ID | 内容 |
|----|------|
| F-01 | `fullScreenCover` + `interactiveDismissDisabled` |
| F-02 | Hub 復帰は **停車 or 到着/途中下車**（離脱 = Hub 復帰） |
| F-03 | フォーカス内で到着・延長も可能 |
| F-04 | 延長はフォーカス継続（Hub に戻らない） |
| F-05 | デフォルト: 見積もり連動カウントダウン |
| F-06 | アプリ FG/BG は進行に影響しない（Date ベース） |
| F-07 | 超過: アラーム + 3 択 |
| F-08 | 3 択: もう終わってた / ちょうど終わった / 延長（どのくらい・なぜ） |
| F-09 | UI 最小限: タスク名、タイマー、コントロール |
| F-10 | 音はデフォルト ON |
| F-11 | OS レベルの他アプリブロックはしない（アプリ内フォーカスのみ） |
| F-12 | フォーカス表示中かつ充電中（満充電含む）は、設定が ON なら自動ロックしない。既定 ON |
| F-13 | Focus 内で割り込み発券可。Hub と同じ親指発券シート。単発発行で今の切符を停車し新切符で発車。カバーは維持 |
| F-14 | **車内放送**: 長い乗務の途中に予測不能な進捗問い。超過 3 択と同じ操作盤差し替え。ウィザード禁止 |
| F-15 | 進捗放送の本数: 10 分以下は 0、11–25 分は 1、30 分以上は 2。当初見積もり基準。次の放送までのカウントは出さない |
| F-16 | 4 択: まだこれ / 停車 / もう終わってた / 延長しそう。スコアにしない |
| F-17 | 走行中にアプリが背面なら 45–90 秒で「まだ乗ってる？」通知（進捗と同時なら away を捨てる）。AlarmKit は使わない |
| F-18 | 車内放送は設定で OFF 可。既定 ON |

### 定時（喜び / ハック耐性）

| ID | 内容 |
|----|------|
| U-01 | **到着の案内**: 到着した時点でマルス券を手元に出し、ユーザーが検札印を押す＋ haptic。完了そのものを先に祝う。破り・見出しトーストは出さない |
| U-02 | **定時到着**は同じ案内の見出し味付け（当初見積もりの帯域内・15%・下限 45 秒）。延長後予算では見ない |
| U-03 | **早着**はいい結果として「早着」案内＋見積/実績。超過は「到着」のみ（差を突き付けない・延着バッジなし） |
| U-04 | 祝祭はエフェメラ。永続スコア・ストリーク・解除なし |
| U-05 | **定時運行**: その運行で到着が 1 件以上、かつ遅延なし（定時・早着は可）。空の運行は対象外 |
| U-06 | 履歴は「定時」「早着」「到着」。日次 / 週次に定時率・件数 KPI を出さない |

## 却下したオプション

| 却下 | 代替 |
|------|------|
| インボックスへ戻す | 到着整理 / 途中下車→乗り継ぎ |
| 同一切符の書き換え（乗り換え） | 分割 + 乗り継ぎ |
| コーチング質問ウィザード | 掃き出しキャンバス |
| Override のハード制限（1日1回等） | 「今日 n 回目」のみ |
| システム自動ソート | 手動並べ替えのみ |
| 繰り返しタスク | 履歴「今日に追加」（v1） |
| Hub に完了タスク表示 | アーカイブ |
| 5分〜8時間スケール | 60分上限・7プリセット |
| 初期タグプリセット | なしスタート |
| 全日運行 Live Activity | 発車中 LA + Widget（v1） |
| 24h 自動 Pause | 運行開始/終了 |
| Mac 土管に SwiftData CloudKit | 正規ユーザー以外不可（Apple 含む）を満たさない。X-09 |
| Mac v1 の LAN / Bonjour | 社内 Wi-Fi でクライアント分離があり得る。インターネットリレー |
| Mac 同期のアカウント発行 | ペアリング + 許可後の鍵 |
| QR に masterKey を載せる | 短命オファー + 画面に出ない confirm HMAC + 双方 LA |
| 画面録画だけでペアできること | 両方の画面が常時録画でも、端末を操作して LA する本人だけが確定できる |
| 照合数字（SAS）を人の防御にする | 見ない。相手は画面を Mac に向ける同時光学交換で束縛する |
| 最初の QR 読取だけでリレーに相手を固定する | 録画からの先着が「許可しますか」になる |
| WebAuthn PRF を内容の主鍵にする | Keychain のマスター鍵。PRF は後回しの wrapping |
| 同期のための APNs / 背面起こし | 前面または `ScenePhase.active` 復帰で逐次反映 |
| ストリーク / XP / 定時率 | エフェメラな到着案内のみ。KPI 化すると見積もり水増しが合理になる |
| 早着を祝わない | 早着はいい結果。見出し「早着」＋見積/実績。定時到着とは別見出し |
| 超過到着の祝祭取り下げ | 完了を先に祝う。超過は記録・超過 UI に留め、到着の喜びは取り上げない |
