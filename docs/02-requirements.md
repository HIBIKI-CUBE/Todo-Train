# 02 — 守ること・やらないこと・未決

画面の手順やフィールド一覧はコードを見る。ここは **プロダクトとして壊してはいけない約束** だけ。

## 守ること

- 1 切符 = 1 タスク。大幅な書き換えはしない。残りは **途中下車 → 乗り継ぎ（新切符）**
- 掃き出しの摩擦を最小化。Inbox にハード上限は置かない
- 並べ替えは人の意志。期限があっても自動ソートしない
- 見積もりは **60 分上限**（Planning Fallacy。[07](07-research.md)）
- **走行中は同時 1 件。** 停車はいつでも可。上限は **新規発車** だけ止める
- 発車は運行中のみ。フォーカスを閉じることと到着は別
- アプリ内ではフォーカスを維持する。OS レベルで他アプリを止めない
- 車内放送は予測不能な短い問い。ウィザードでもスコアでもない。次までのカウントは出さない。ロック中は出さない
- 定時の喜びは消える瞬間だけ。履歴に率や件数 KPI を出さない。超過でも到着の祝祭は取り下げない。早着はいい結果。判定は当初見積もり（延長後予算では見ない）
- 繰り返しタスクは作らない。履歴から「今日に追加」
- タグに初期プリセットを置かない
- AI は控えめ。見積の骨格は Heuristic。PCC はユーザーが起動したときだけ＋「Private Cloud で処理」。Focus 中に会話 AI を自動起動しない
- 履歴の空き時間は折り畳まない（乗車と同じ縮尺）

同期と Mac の役割は [13](13-sync-mac-companion.md) / [14](14-mac-companion-ux.md)。見た目の骨格は [12](12-ui-design.md)。

## やらないこと

| やらない | なぜ |
|----------|------|
| インボックスへ戻す | 途中下車 → 乗り継ぎで閉じる |
| 同一切符の書き換え（乗り換え） | 表象の書き換えコスト。分割する |
| コーチング質問ウィザード | 道具である。掃き出しキャンバスで足りる |
| 臨時停車で枠を増やす | WIP を停車ではなく発車側に置く |
| システム自動ソート | 意志ある並べ替え |
| 繰り返しタスク | 「今日に追加」 |
| Hub に完了を残す | アーカイブ |
| 数時間スケールの見積 | 60 分で unpacking させる |
| 全日運行 Live Activity | 8 時間で死ぬ。[07](07-research.md) |
| 24h 自動 Pause | 運行開始 / 終了 |
| ストリーク / XP / 定時率 | 測ると見積もり水増しが合理になる |
| 早着を普通の到着に埋める | いい結果として見出しを分ける |
| 超過到着の祝祭取り下げ | 責めになる。完了を先に祝う |
| JSON エクスポートを同期代わり | 不要 |
| iPad / 系譜の可視化 | 意図的に未着手 |
