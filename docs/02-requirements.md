# 02 — 確定要件・却下・未決

## 確定要件

### タスク（切符）

| ID | 内容 |
|----|------|
| T-01 | 各タスクは列車の切符モチーフ |
| T-02 | 属性: 名前、タグ、見積もり、（期限は v1 defer） |
| T-03 | 見積もり **上限 60 分** |
| T-04 | プリセット: **5 / 10 / 15 / 20 / 30 / 45 / 60** 分 |
| T-05 | 任意カスタム入力は v1 で検討（MVP 必須ではない） |
| T-06 | 開始済みは進捗比率（実績/見積もり）を表示可能 |
| T-07 | タグ: 色+名前、複数可、管理画面の並び最上位=デフォルト |
| T-08 | タグ初期プリセットなし |
| T-09 | 1 切符に何度でも乗車可（停車→再発車） |
| T-10 | 完了はアーカイブ（Hub 非表示、履歴に残る） |
| T-11 | 繰り返しタスク不要 → 履歴から「今日に追加」（**v1**） |
| T-12 | 既存切符の大幅書き換え禁止 → **分割のみ** |
| T-13 | 子タスクは **乗り継ぎ** リンクで系譜をたどる |
| T-14 | 新規作成時に挿入位置指定可（デフォルト末尾） |
| T-15 | 乗り継ぎ先作成時も挿入位置指定 |

### Hub / Inbox

| ID | 内容 |
|----|------|
| H-01 | 随時追加のインボックス型 |
| H-02 | FAB → **即キーボード**、連続追加 |
| H-03 | タイプ → 見積もりチップ 1 タップ → 完了 |
| H-04 | 挿入位置変更: 見積もりチップ長押し等（上級操作） |
| H-05 | カードタップ=詳細、横に発車ボタン |
| H-06 | ミニマルカード + 列車テーマ |
| H-07 | 停車中を Hub にバッジ表示 |
| H-08 | 停車上限 **デフォルト 2**（設定で 3） |
| H-09 | 走行中は同時 **1** 件のみ |
| H-10 | MVP: Hub 内ドラッグ並べ替え。専用並べ替えビューは **v1** |
| H-11 | Inbox 総数にハード上限なし |
| H-12 | **タグ UI は MVP に含む** |

### 運行（Service Day）

| ID | 内容 |
|----|------|
| S-01 | **運行開始 / 運行終了** で 1 日のメリハリをつける |
| S-02 | **発車は運行中のみ** |
| S-03 | 日付が変わったら翌日起動時に運行終了フローを出す |
| S-04 | 運行終了時、停車中・未到着は **途中下車 → 乗り継ぎ切符**（行ごとに放棄可） |
| S-05 | 走行中は運行終了不可（先に停車/到着） |

### フォーカス

| ID | 内容 |
|----|------|
| F-01 | `fullScreenCover` + `interactiveDismissDisabled` |
| F-02 | Hub 復帰は **停車 or 到着/途中下車**（離脱 = Hub 復帰） |
| F-03 | フォーカス内で到着・延長も可能 |
| F-04 | 延長はフォーカス継続（Hub に戻らない） |
| F-05 | デフォルト: 見積もり連動カウントダウン |
| F-06 | アプリ FG/BG は進行に影響しない（Date ベース） |
| F-07 | 超過: アラーム + 3 択 |
| F-08 | 3 択: もう終わってた / ちょうど終わった / 延長（どのくらい・なぜ） |
| F-09 | UI 最小限: タスク名、タイマー、コントロール |
| F-10 | 音はデフォルト ON |
| F-11 | OS レベルの他アプリブロックはしない（アプリ内フォーカスのみ） |

### Force-quit / 復帰

| ID | 内容 |
|----|------|
| Q-01 | ホーム退避: セッション継続、復帰でフォーカス復帰 |
| Q-02 | Force-quit: 次回起動で Date 再計算。**同じ運行日内なら走行継続**（超過なら超過 UI） |
| Q-03 | 運行終了済みの日なら運行終了処理に乗せる |

### 停車上限・到着整理

| ID | 内容 |
|----|------|
| P-01 | 上限到達はソフトブロック（解決シート） |
| P-02 | 解決シート最優先: **先に停車中を解決** |
| P-03 | 「インボックスへ戻す」は廃止 → 到着整理 |
| P-04 | 到着整理は **質問ウィザード禁止**。掃き出しキャンバス |
| P-05 | 臨時停車許可（Override）: セーフティロック UI |
| P-06 | Override: **回数制限なし**。「今日 n 回目」のみ。統計記録 |
| P-07 | PCC 利用時は「Private Cloud で処理」注釈 |

### 定時（喜び / ハック耐性）

| ID | 内容 |
|----|------|
| U-01 | **到着の案内**: 到着した時点で短い駅案内＋ success haptic。完了そのものを先に祝う |
| U-02 | **定時到着**は同じ案内の見出し味付け（当初見積もりの帯域内・15%・下限 45 秒）。延長後予算では見ない |
| U-03 | 超過・早着でも案内は取り下げない。差を突き付けるキャプションや「延着」バッジは出さない |
| U-04 | 祝祭はエフェメラ。永続スコア・ストリーク・解除なし |
| U-05 | **定時運行**: その運行で到着が 1 件以上、かつ到着がすべて定時。空の運行は対象外 |
| U-06 | 履歴は観測用に「定時」バッジのみ（それ以外の到着は「到着」）。日次 / 週次に定時率・件数 KPI を出さない |

## 却下したオプション

| 却下 | 代替 |
|------|------|
| インボックスへ戻す | 到着整理 / 途中下車→乗り継ぎ |
| 同一切符の書き換え（乗り換え） | 分割 + 乗り継ぎ |
| コーチング質問ウィザード | 掃き出しキャンバス |
| Override のハード制限（1日1回等） | 「今日 n 回目」のみ |
| システム自動ソート | 手動並べ替えのみ |
| 繰り返しタスク | 履歴「今日に追加」（v1） |
| Hub に完了タスク表示 | アーカイブ |
| 5分〜8時間スケール | 60分上限・7プリセット |
| 初期タグプリセット | なしスタート |
| 全日運行 Live Activity | 発車中 LA + Widget（v1） |
| 24h 自動 Pause | 運行開始/終了 |
| ストリーク / XP / 定時率 | エフェメラな到着案内のみ。KPI 化すると見積もり水増しが合理になる |
| 早着を定時扱い | 帯域内のみ。早着は通常の到着（案内は出す） |
| 超過到着の祝祭取り下げ | 完了を先に祝う。超過は記録・超過 UI に留め、到着の喜びは取り上げない |

## 未決・仮説（実装中に検証可）

| 項目 | 状態 |
|------|------|
| セッション中チェックイン（25/50/75%） | MVP は超過時のみ。v1 で要確認 |

| Hub 10–15 件処理リマインド | 研究推奨、未確定 |
| 見積もり 0 分 | 未定義（避ける UI で可） |
| 7プリセットの最適性 | 仮説 — 使用頻度で調整 |
| FAB 即キーボード UX | 仮説 |
| セーフティロック Override 感触 | 仮説（v0.5） |
