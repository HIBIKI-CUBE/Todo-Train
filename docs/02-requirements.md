# 02 — 守ること・やらないこと・未決

画面の手順やフィールド一覧はコードを見る。ここは **プロダクトとして壊してはいけない約束** だけ。

## 守ること

- 1 切符 = 1 タスク。大幅な書き換えはしない。残りは **途中下車 → 乗り継ぎ（新切符）**
- 掃き出しの摩擦を最小化。Inbox にハード上限は置かない
- 並べ替えは人の意志。期限があっても自動ソートしない
- 見積もりは **60 分上限**（Planning Fallacy。[07](07-research.md)）
- **走行中は同時 1 件。** 停車はいつでも可。上限は **新規発車** だけ止める
- 発車は運行中のみ。フォーカスを閉じることと到着は別
- アプリ内ではフォーカスを維持する。OS レベルで他アプリを止めない
- 車内放送は予測不能な短い問い。ウィザードでもスコアでもない。次までのカウントは出さない。ロック中は出さない
- 定時の喜びは消える瞬間だけ。履歴に率や件数 KPI を出さない。超過でも到着の祝祭は取り下げない。早着はいい結果。判定は当初見積もり（延長後予算では見ない）
- 繰り返しタスクは作らない。履歴から「今日に追加」
- タグに初期プリセットを置かない
- AI は控えめ。見積の骨格は Heuristic。発車前の到着予測も中央値を骨格にし、オンデバイスで題名・開始時刻・見積と延長・早着を見て分を調整する。モデルは思考つきの構造化出力を返し、案内板には分数だけ出す。開いている切符は裏で温め、持ち上げた切符は列の前に出す。骨格は到着ですぐ動き、モデルは題名・時間帯が変わったら取り直す。学習から外すのは発車直後の到着だけ（開始忘れ）。早着そのものは残す。PCC はユーザーが起動したときだけ＋「Private Cloud で処理」。Focus 中に会話 AI を自動起動しない
- 履歴の空き時間は折り畳まない（乗車と同じ縮尺）
- 運転は人がする。カレンダーは運転しない。ダイヤと走行が重なったら ATS が網になる。発車は止めない。**日常の発車・停車・再乗車を確認で阻まない。確認は不可逆な操作だけ。** 指図しない。計器として必要十分な情報を乗務の現場に出す。見たいときに見える。着発／通過は手であり、発車の授業ではない。予定は仕事の材料ではない。時刻付きの枠は占有の事実。
- **運行の端は搭乗と起動／シャットダウン。** 運行開始で即枠は開く。端は Focus の盤。門に入ると日常面が消え、**起動**の一手のあと盤が光って起き上がり、**発車用意**でホームへ空間が開く。揃えは点検リストではない。着発は任意。発券と並べ替えは Hub の手のまま複製しない。終了は落ちる前に今日の跡と履歴と同じ日次の事実を出す。受領でもウィザードでも成績でもない。率・ランクは出さない。門のあいだも発車は阻まない。延長理由は Focus では任意。未記入はシャットダウンの跡でだけ触れる。

同期と Mac の役割は [13](13-sync-mac-companion.md) / [14](14-mac-companion-ux.md)。見た目の骨格は [12](12-ui-design.md)。

## やらないこと

| やらない | なぜ |
|----------|------|
| インボックスへ戻す | 途中下車 → 乗り継ぎで閉じる |
| 同一切符の書き換え（乗り換え） | 表象の書き換えコスト。分割する |
| コーチング質問ウィザード | 道具である。掃き出しキャンバスで足りる |
| 臨時停車で枠を増やす | WIP を停車ではなく発車側に置く |
| システム自動ソート | 意志ある並べ替え |
| 繰り返しタスク | 「今日に追加」 |
| Hub に完了を残す | アーカイブ |
| 数時間スケールの見積 | 60 分で unpacking させる |
| 全日運行 Live Activity | 8 時間で死ぬ。[07](07-research.md) |
| 24h 自動 Pause | 運行開始 / 終了 |
| ストリーク / XP / 定時率 | 測ると見積もり水増しが合理になる |
| 早着を普通の到着に埋める | いい結果として見出しを分ける |
| 超過到着の祝祭取り下げ | 責めになる。完了を先に祝う |
| JSON エクスポートを同期代わり | 不要 |
| CloudKit を土管に使う / ゲートを true にする | 鍵が Apple 側。[13](13-sync-mac-companion.md) / [04](04-architecture.md) |
| iPad / 系譜の可視化 | 意図的に未着手 |
| 乗り継ぎキャンバスのゲージ統一 | Phase 2。意図的に未着手 |
| ATO（運行の自動開始終了、並べ替え、発車拒否、先回り停車、ダイヤ終了の自動再乗車） | 技能と自己効力感を奪う。ATS は網であり運転ではない |
| 日常の発車・停車・再乗車を確認で止める | 阻むのは不可逆だけ。網は ATS |
| 指図する案内・「して」の授業 | 自分でコントロールできている感覚を奪う。計器と手だけ |
| 車内放送 away をダイヤの網にする | ロック中は away 自体が出ない。ダイヤ接近中は away を出さない |
| 掲示のままで ATS | 着発が if-then の符号化。通過の予定は線路を塞がない |
| Hub に掲示リストを常設する / ダイヤを開けと促す | 状況認識は乗務の現場の計器（いまと次）。タブ閲覧は別行動。門のあいだだけ着発の手が使えるのは常設ではない |
| 運行開始の受領・点呼・始発の押印 | 指令が上にいる。押印は到着の完了。起動は自分が門を出てホームに立つ |

カレンダー体験の摩擦は契約を変えずに直す。[17](17-calendar-experience.md)。
