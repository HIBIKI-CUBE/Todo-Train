# Mac 発券〜発車の演出（f20・確定）

モック：[mac-ticketing-f20.html](./mac-ticketing-f20.html)（#192）

## 状態
- デザインは確定。Mac への実装時期は未定。

## 入力
- 2本指の縦ストロークで分数を決める（5/10/15/20/30/45/60 分）。
- そのまま横フリックで行き先を選ぶ：右＝発車、左＝保存。
- 指を離す前ならキャンセルできる。どちらを選んでも待ち時間はない。

## きっぷ
- 剛体のカード1枚。拡大縮小しない。まっすぐ出てくる。
- 発車するのはきっぷ。発券 UI ではない。

## 動き
- f14 のタイムラインのまま：rAF のマスタータイムライン1本、全体で約 0.82 秒、重い発券機、短い静止。
  - 発券機 machineMs 520 / 送り feedMs 300 / はけ exitMs 280。
- 有機的な動きはなし。光はくっきり、にじませない。

## 色
- 使うのは3色だけ：青 rail `#739EC7`、緑 signalGreen `#59C785`、琥珀 signalAmber `#FFB847`。
- 発車側（右フリック）は、溜め中と上限では青。ready で一度だけ緑に切り替わる。
- 保存側（左フリック）は琥珀。

## カタパルト（誘導レール）
- 排出口の両端からホログラムのガイドレールが伸びる。明るさの波がレールに沿って流れる（波の間隔 110px）。
- シェブロンはうっすら、幅広でぴっちり詰まったトラテープ型。形だけで、黄色と黒にはしない。
- 点滅するのは排出口だけ。カタパルトは点滅せず、誘導に徹する。
- カタパルトは発券機から照射される設定。発券機の動きにそのまま付いていく。
- 長さは f19 の約 1.4 倍。遠いほどほぼ直線的に薄くなり、先端で 0。
- 発券機がはけるあいだ、先端から排出口へ向かってイージング付きで縮み、画面から消える直前に縮み終わる。
- 発車の光はきっぷの先端と一緒に動く。
