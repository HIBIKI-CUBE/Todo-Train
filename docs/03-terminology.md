# 03 — 用語表

UI 文言・ドメイン名・コード識別子で言い換えない。特に「乗り換え」「区間完了」「コーチ」は使わない。

| 用語 | コード | 定義 |
|------|--------|------|
| **切符** | `Ticket` | 1 つのタスク。Swift の `Task` と衝突するのでこの名前 |
| **Hub** | Hub | 未完了切符の中心画面 |
| **運行** | `ServiceDay` | 1 日の作業枠 |
| **発車** | board | フォーカスセッション開始 |
| **停車** | pause | 中断。Hub に戻れる。上限のカウント対象 |
| **到着** | `arrived` | 完了の明示 → アーカイブ |
| **途中下車** | `partialDisembark` | 区間は終わるが全体は未完了 |
| **乗り継ぎ** | `TaskLineage` | 途中下車から生まれた新切符へのリンク |
| **放棄** | `abandoned` | もう乗らない |
| **到着整理** | Remaining tickets canvas | 残作業を新切符として掃き出す。ウィザードではない |
| **超過** | `overtime` | 見積もり超過 |
| **延長** | extend | 見積もりを足してフォーカス継続 |
| **割り込み** | interrupt issue | 今の乗車を停車し、新切符で発車。書き換えではない |
| **再乗車** | resume | 停車中切符の再発車 |
| **定時到着 / 早着** | — | 到着案内の見出し味付け。点数にしない |
| **定時運行** | — | その運行の到着に遅延がなかった短い案内（早着は可） |
| **車内放送** | check-in | 乗務中の短い問いと、他アプリへ離れたときの「まだ乗ってる？」。ロック中は出さない |

使わない: 乗り換え、インボックスへ戻す、区間完了、コーチ、ポイント / XP / ストリーク / 定時率。  
**臨時停車許可**（Override）は廃止。停車は常に可。上限は新規発車。
