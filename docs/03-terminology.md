# 03 — 用語表

UI 文言・ドメイン名・コード識別子で言い換えない。特に「乗り換え」「区間完了」「コーチ」は使わない。

| 用語 | コード | 定義 |
|------|--------|------|
| **切符** | `Ticket` | 1 つのタスク。Swift の `Task` と衝突するのでこの名前 |
| **Hub** | Hub | 未完了切符の中心画面 |
| **運行** | `ServiceDay` | 1 日の作業枠 |
| **発車** | board | フォーカスセッション開始。確認で阻まない。確認は不可逆な操作だけ |
| **停車** | pause | 中断。Hub に戻れる。上限のカウント対象。ATS が停めた枠は占有中は数えない |
| **到着** | `arrived` | 完了の明示 → アーカイブ |
| **途中下車** | `partialDisembark` | 区間は終わるが全体は未完了 |
| **乗り継ぎ** | `TaskLineage` | 途中下車から生まれた新切符へのリンク |
| **放棄** | `abandoned` | もう乗らない |
| **到着整理** | Remaining tickets canvas | 残作業を新切符として掃き出す。ウィザードではない |
| **超過** | `overtime` | 見積もり超過 |
| **延長** | extend | 見積もりを足してフォーカス継続 |
| **割り込み** | interrupt issue | 今の乗車を停車し、新切符で発車。書き換えではない |
| **再乗車** | resume | 停車中切符の再発車 |
| **定時到着 / 早着** | — | 到着案内の見出し味付け。点数にしない |
| **定時運行** | — | その運行の到着に遅延がなかった短い案内（早着は可） |
| **車内放送** | check-in | 乗務中の短い問いと、他アプリへ離れたときの「まだ乗ってる？」。ロック中は出さない |
| **掲示** | notice | カレンダーのライブ参照。着発しなくても占有の計器に出る。線路は塞がない。今日の通過駅 |
| **ダイヤ** | `TimetableBlock` | 自分が運行から外した占有。乗る対象ではない。今日の停車駅。「予定の到着」は見積の印字時刻 |
| **着発 / 通過** | adopt / unadopt | 予定を今日の停車駅にする／抜ける。行先票の題名が駅。繰り返しは今回だけ / 今後も。乗務の停車とは別 |
| **掲示するカレンダー** | `timetableVisibleCalendarIDs` | 図表に出す掲示のフィルタ。着発／通過とは別。隠してもダイヤは残る |
| **スジ** | strip | 図表の帯。濃いスジがダイヤ、薄いスジが掲示 |
| **待避** | pause | ダイヤのための操作は既存の停車。新ボタンにしない |
| **ATS** | `TimetableGuard` | ダイヤと走行が重なったときの網。UI に出さない |
| **予定の到着** | scheduled arrival | いま発車したときの見積印字時刻。残り時間ではない |
| **予測の到着** | predicted arrival | タグ＋時間帯の中央値（＋任意のオンデバイス調整）。記録された到着ではない |

使わない: 乗り換え、インボックスへ戻す、区間完了、コーチ、ポイント / XP / ストリーク / 定時率。  
**臨時停車許可**（Override）は廃止。停車は常に可。上限は新規発車。

タブは **切符 / ダイヤ / 履歴 / 設定**。ダイヤはカレンダー同期画面ではない。今日の運転図表（計画の符号化）であり、乗務の決断は Focus / 案内板、網は ATS。履歴のアイコンは `clock` のままなので、ダイヤは `calendar`。契約と日常の摩擦は [17](17-calendar-experience.md)。

## 文体

基準は Apple 純正アプリの日本語 UI（人間の文）。LLM が日本語化した UI 文は、同じ原文の Apple 訳より常体の言い切りと「〜する」ラベルが有意に多い。それを避ける。

- 状態・結果・説明は です・ます。「送った」「つながらない」ではなく「送りました」「つながりません」。
- ボタンは動詞の辞書形か名詞で止める（「閉じる」「追加」）。「追加する」まで書かない。
- 説明は 2 文まで。2 文なら両方 です・ます で閉じる。体言止めを続けない。
- VoiceOver ヒントは です・ます で、何が起きるかを言う。
- 例外は利用者自身の声だけ。車内放送への答え（「まだやってる」）と車内放送の問い（「まだ乗ってる？」）。
- 感覚で禁止を足さない。ダッシュや「A ではなく B」は測っても人間の文と差がなかった。

門は `tools/wording/check.py`（CI `wording`）。例外は `tools/wording/allow.tsv` に理由つきで足す。
