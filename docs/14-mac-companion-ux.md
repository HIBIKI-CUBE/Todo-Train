# 14 — Mac コンパニオン体験

土管は [13](13-sync-mac-companion.md)。iPhone の Hub / Focus / マルス券は移植しない。

確認 1–6 は確定（1–2 は 2026-09-12、3–6 は提案値を 2026-09-19 に採用）。

仕事中は Mac が正面、iPhone は机の端か Focus のまま。机の横目で「何に乗っているか」を見て、必要なら停車・再乗車する。列車の切符を並べたり、到着の 3 択をしたりはしない。

## 決めたこと

- 殻は **メニューバー accessory**（Dock に出さない）。終了は extra メニューの末尾。未ペアのクリックは吹き出しで即ペアリング。ペアリング専用ウィンドウは持たない
- 乗務中だけ **小さな PiP**。Hub 窓ではない。ADHD はすぐ他のことを始めるので、乗っているあいだは隅に出し続ける。タイムアウトで自動隠ししない
- 操作は **停車と再乗車**。到着・延長・割り込み・発券・運行開始/終了は iPhone
- 乗務なしのバーは **アイコンのみ**
- 超過は表示だけ。3 択は出さない
- コマンドは楽観的に走行を止めない。「iPhone に送った」で待つ。背面を失敗扱いにしない
- カメラ無し Mac は例外のまま（SYNC-4 では未実装。主経路はセルフィー）

進捗の「まだ乗ってる？」だけ PiP に出す。車内放送の 4 択・停車上限シートは iPhone。運行中で乗っていないときの「運行は続いてる」は通知だけ（PiP なし）。発火は iPhone。ペアしても iPhone の idle 通知は残す。

いま、なければ次の占有（ダイヤまたは掲示）は PiP に出す。残り時間のバーに帯と印。時刻・残り分・題名。停車が主。ダイヤの保護境界に達したら、同じ停車コマンドを一度だけ送る。決定の代行はしない。乗務現場でいまと次が読めない摩擦は [17](17-calendar-experience.md)。

見た目は [12](12-ui-design.md) に合わせる。Focus の純黒運転台は macOS に複製しない。

## 確認の記録

同期（E2E / CFW / 起こしなし）は [13](13-sync-mac-companion.md) で確定済み。ここでは体験だけ。

1. **殻はメニューバー accessory でよいか。** **確定（2026-09-12）。** ペアリング用の別ウィンドウは持たない。未ペアのクリックは吹き出しで即ペアリング。乗務中の小さな PiP は同日に追加（Hub 窓ではない）
2. **操作は停車だけでよいか。** **確定（2026-09-12）。** 机から再乗車も置く。到着・延長は iPhone
3. **乗務なしのときバーに文字を出すか。** **確定（2026-09-19）。** アイコンのみ
4. **超過を Mac でどう見せるか。** **確定（2026-09-19）。** 表示だけ（3 択なし）
5. **送信中（iPhone が背面）をどこまで丁寧にするか。** **確定（2026-09-19）。** 「送った」で待つ。背面を失敗扱いにしない
6. **Mac にカメラが無いときの落とし方は例外でよいか。** **確定（2026-09-19）。** 例外のまま。SYNC-4 では未実装でよい。主経路はセルフィー（ウェブカメラ必須）
