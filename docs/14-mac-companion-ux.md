# 14 — Mac コンパニオン体験

土管と脅威は [13](13-sync-mac-companion.md)。iPhone の Hub / Focus は移植しない。マルス券面は「いまやる」の発行アニメだけ共有する。

仕事中は Mac が正面、iPhone は机の端か Focus のまま。机の横目で「何に乗っているか」を見て、必要なら停車・再乗車する。列車の切符を並べたり、到着の 3 択をしたりはしない。

## 約束

- 殻は **メニューバー accessory**（Dock に出さない）。終了は extra メニューの末尾。未ペアのクリックは吹き出しで即ペアリング。ペアリング専用ウィンドウは持たない
- 乗務中と、到着の印のあとの空白だけ **小さな PiP**。Hub 窓ではない。ADHD はすぐ他のことを始めるので、乗っているあいだは隅に出し続ける。タイムアウトで自動隠ししない。空白の PiP は予約の券面 1 枚か「運行は続いてる」だけで、切符を選ぶ画面にしない。空白が終わるか、閉じるか、発車したらしまう
- 操作は **停車と再乗車**、声掛けへの答え（続行・延長・到着済み・停車）、それにペア済み・運行中だけの **いまやる**（題名＋所要を Mac のパネルで確定 → PiP の位置にマルス券面 → 発車）。確定は発行＋発車の一拍。在庫だけ残す経路は出さない。乗務中は確認なしで割り込み発車する。タグは出さない。延長は 5・10・15 分。運行の開始と終了は iPhone。到着済みを送っても、返事の前に乗務を終えた表示にはしない。Focus の純黒運転台は複製しない
- いまやるの入力は Mac のパネル（題名と所要）。所要は 5・10・15・20・30・45・60 分。券面はそこに出さない。ack が通ってから、PiP の位置で画面の横からマルス券面が滑り出し、ひと息置いてから snap の乗務が同じ位置の PiP に替わる。ack の前に券面は出さない。snap が来ないあいだは待ちを出し、返事がなければしまう。設定でキーボードショートカットを付けられる。ペア済み・運行中だけ開く。楽観で偽の乗務は出さない
- iPhone が前面（または `ScenePhase.active`）でないとコマンドは届かない。机の端で起きていることが前提。ロック中受信は別 slice
- 乗務なしのバーは **アイコンのみ**。到着後の空白で予約があるあいだは、メニューに「予約の切符で発車」を足す。空白が終わるとその行は消え、バーはアイコンのみに戻る
- 超過も同じ問いを PiP に出す。段が進んでも文は同じで、自分の番だけ音を一度出す。しまった PiP は引き出さず、端の保留灯だけ点ける
- コマンドは楽観的に走行を止めない。「iPhone に送りました」で待つ。背面を失敗扱いにしない
- ペアリングの主経路はセルフィー。カメラ無し Mac は例外のまま（貼り付けフォールバックはしない）
- 約束の版が範囲の中なら、診断の一行以外は出さない。範囲の外では、メニューに、どちらを更新すれば操作が届くかを出す。まだ知らない操作は実行せず、その操作のそばに更新の案内を出す

声掛けは PiP の問いと 4 択。在席中の Mac が先に鳴り、iPhone とは同時に鳴らさない。到着後の空白も同じ交代で、3 分と 6 分に 1 回ずつ、同時には鳴らさない。iPhone が声掛けを載せないときは、従来の「まだ乗ってる？」と続行・停車のまま。停車上限のシートは iPhone。到着の印から空白のあいだは、予約の券面か「運行は続いてる」を PiP に出す。それよりあとの「運行は続いてる」は通知だけ（PiP なし）。発火は iPhone。ペアしても iPhone の idle 通知は残す。Focus には次の切符の予告を出さない。

いま、なければ次の占有（ダイヤまたは掲示）は PiP に出す。残り時間のバーに帯と印。時刻・残り分・題名。停車が主。PiP の停車と車内放送の 4 択の停車は、利用者が停めた停車として送る。ダイヤの保護境界に達したら、ダイヤが停めた停車として、同じ停車コマンドを一度だけ送る。理由の付いていない停車が届いたときは、同じ乗車の保護境界の前後 60 秒ならダイヤの停車、それ以外は利用者の停車とみなす。理由を選ばせる画面は出さない。決定の代行はしない。乗務現場でいまと次が読めない摩擦は [17](17-calendar-experience.md)。

見た目は [12](12-ui-design.md) に合わせる。Focus の純黒運転台は macOS に複製しない。
