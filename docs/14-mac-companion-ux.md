## 提案する体験（v1）

仕事中は Mac を正面にしている。iPhone は机の端か Focus 表示のまま。列車の切符を並べたり、到着の 3 択をしたりはしない。

| 要素 | 提案 |
|------|------|
| 殻 | **メニューバー常駐**（Dock に出さない accessory） |
| バー上 | 短いタイトル（切れ）+ 残り。乗務なしはアイコンのみ |
| クリック | ポップオーバー。未ペアなら即ペアリング。ペア済みならフルタイトル、大めの残り、停車 |
| 操作 | **停車だけ**。再開・到着・延長・発券・運行開始/終了は iPhone |
| ログイン時起動 | 既定 ON（道具として常にそこにある） |
| ウィンドウ / Hub | 持たない |

iOS の Live Activity を机のメニューバーに移した形。運転台そのものではない。

## 状態（ユーザーが見るもの）

同期の `phase` / ack を、画面の言葉に落とす。ポーリングしているようには見せない。残りは端末内の Date 計算。

| 状態 | バー | ポップオーバー | 停車 |
|------|------|----------------|------|
| 未ペア | アイコン | クリックで即ペアリング（正方のカメラ枠 + Mac の QR） | なし |
| 乗務なし | アイコン | 「乗務なし」 | 置けない |
| 走行中 | タイトル切れ + 残り | フルタイトル + 残り + 停車 | 置ける |
| 超過 | タイトル切れ + 超過の残り | 超過であることが分かる。3 択は出さない | 置ける（停車は可。到着の判定は iPhone） |
| 停車中 | アイコン、または「停車中」短い表示 | タイトル + 停車中。再開ボタンは出さない | 置けない |
| 送信中 | 走行中のまま | 停車は「iPhone に送った」。連打しない | 同じ cmd を再送しない |
| 送れなかった | 走行中のまま | 一行。停車上限 / 乗務が変わった など。ウィザードなし | もう一度押せる |
| 回線なし | 最後の snap を Date 計算で仮表示、またはアイコン | 「iPhone とつながっていない」 | 置ける（FIFO に残る。届くのは iPhone が前面に来てから） |

「送れなかった」の文言は ack の `error` だけを使う。サーバの生エラーやスタックは出さない。

超過 3 択・車内放送・臨時停車シートは Mac に出さない。iPhone の Focus が本尊。

## 停車の手触り

1. ポップオーバーで停車を押す
2. すぐ「iPhone に送った」にする（楽観的に走行を止めない。本尊は iPhone）
3. ack `ok` + snap が `paused` → 「停車中」
4. ack `ok: false` → 走行のまま、一行理由
5. iPhone が背面 → 送信中のまま待ち。前面に来たとき反映。Mac から起こさない

停車上限に当たったときは iPhone 側で解決シートが出る（既存）。Mac は「停車できません（停車上限）」だけで、解決 UI は持たない。

## ペアリングの体験

プロトコルは [13](13-sync-mac-companion.md)。数字を見比べさせない。画面を Mac に向ける一動作。

**一発（主経路）**

1. 未ペアでメニューバーをクリックすると、吹き出しがそのままペアリングになる（別ウィンドウは出さない。追加のボタンも踏まない）
2. 吹き出しの大半は **正方の大きなウェブカメラ枠**。四隅は QR 用。読めたら緑、失敗は赤。Mac 側 QR はその枠の下に載せる
3. iPhone は自分の QR（不透明に描画）+ 正方の前面カメラ枠。説明は「画面を Mac に向ける」
4. 利用者は端末の背面を見ることになる。狙いは Mac のプレビューで合わせ、読めたら haptic
5. 両方読めたら iPhone を自分に戻して Face ID。Mac は **自動で Touch ID**（吹き出しが閉じても確定は続ける）
6. iPhone がつながったあとにオファーを消さない。Mac の Keychain 書き込みが終わるまで待つ
7. 吹き出しを閉じたら、未読取ならカメラとオファーを止める。読取後の Touch ID 中は止めない
8. 収録・スクショ・背面でやり直し

セルフィー中は顔がカメラ側に無いので、Face ID を同じ姿勢でやらない。

**カメラの無い Mac（例外）**

貼り付けと逐次読取。主経路にしない。

解除は iPhone の設定。リカバリは確定後の任意。書き写しのみ。QR にしない。

## やらないこと（体験）

| やらない | 理由 |
|----------|------|
| Hub / マルス券 / 発券 / 並べ替え | 掃き出しは iPhone。机の横目用ではない |
| 履歴・週次・定時の案内 | 振り返りは iPhone |
| 再開・到着・延長・割り込み | フォーカスの意志は運転台に残す |
| 車内放送の 4 択 | iPhone Focus / 通知 |
| Dock アプリアイコン常駐 | メニューバーで足りる |
| 大きな常時ウィンドウ | 横目のコストが増える |
| 同期の仕組み説明（E2E、Workers） | 設定の一行「この Mac だけが読める」程度まで |
| QR と照合数字を同時に出す | 使わない。照合数字自体を人の防御にしない |
| ペアリング QR に秘密を載せる | [13](13-sync-mac-companion.md) |
| 片側の「許可」タップだけで連携済みにする | 録画を見ている第三者が片側を代替できる |
| 最初の読取のあとすぐ Face ID | 見ない照合のゴム印になる。双方の光学読取のあと、端末を自分に戻してから |
| 裏カメラに持ち替えて二度読むのを主経路にする | セルフィー一動作。カメラ無し Mac だけ例外 |

見た目は [12-ui-design.md](12-ui-design.md) に合わせる。メニューバーはシステム標準。Focus の純黒運転台を macOS に複製しない。

## 確認してほしいこと

同期（E2E / CFW / 起こしなし）は [13](13-sync-mac-companion.md) で確定済み。ここでは体験だけ。

1. **殻はメニューバー accessory でよいか。** **確定（2026-09-12）。** 別ウィンドウは持たない。未ペアのクリックは吹き出しで即ペアリング
2. **操作は停車だけでよいか。** 机から再開も要るか
3. **乗務なしのときバーに文字を出すか。** アイコンのみ（提案）か「運休」か
4. **超過を Mac でどう見せるか。** 提案は表示だけ（3 択なし）。超過そのものを出さない方がよいか
5. **送信中（iPhone が背面）をどこまで丁寧にするか。** 提案は「送った」で待つ。失敗扱いにするか
6. **Mac にカメラが無いときの落とし方は例外でよいか。** 主経路はセルフィー一動作（Mac カメラ必須）

2–6 が埋まれば、この紙を確定にする。土管の再議論はしない。
