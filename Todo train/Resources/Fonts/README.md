# Jiskan16s-Depart

Subset TrueType for the Hub 発車 LED board. Glyphs: `発` `車` `>`.

Squares follow the original 16-dot bitmaps:

- Kanji: [jiskan16-2004](http://kanji.zinbun.kyoto-u.ac.jp/~yasuoka/ftp/fonts/) (JIS X 0213, public domain)
- `>`: [shinonome](http://openlab.jp/efont/shinonome/) 8×16 gothic (public domain)

This is the same pairing as JFドットjiskan16s (jiskan16 + 東雲半角), reduced to the three code points the board draws. Do not hand-edit pixels; regenerate from those BDFs.
